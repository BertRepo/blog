## LLM 是什么:从统计到涌现

语言模型的本质是对自然语言序列的概率分布 `P(w_1, w_2, ..., w_n)` 建模,一条清晰的演进脉络是:

- **n-gram 统计模型**:基于马尔可夫假设,用前 n-1 个词预测下一个词 `P(w_t | w_{t-n+1}^{t-1})`,直接用最大似然估计。致命缺陷是维度灾难(组合爆炸)与稀疏性,无法建模长程依赖。
- **神经语言模型**:Bengio 等用词嵌入把离散 token 映射到稠密向量,再接前馈网络。Word2Vec/GloVe 把"分布式表示"发扬光大。
- **RNN/LSTM 时代**:具备序列建模能力,但梯度消失/爆炸与串行计算限制了规模。
- **Transformer-based LLM**:2017 年 Transformer 以纯注意力机制摆脱递归,可大规模并行训练。GPT 系选择 Decoder-only 路线,通过堆叠层数与参数量,在 10^22 FLOPs 量级出现**涌现能力**(in-context learning、思维链推理)——能力随规模非线性跃升,而非线性外推。

参数量通常按 Pre-Norm Transformer 的层数 L、隐藏维 d、头数 h 估算 `N ≈ 12·L·d²`(含 FFN)。Chinchilla 定律进一步指出:给定算力,数据量与参数量应按约 20:1 的 token/参数比同步增长,单纯堆参数会"欠训练"。

## Transformer 架构:Decoder-only 的胜利

原始 Transformer 是 Encoder-Decoder 结构,用于翻译。但 GPT 系为何倒向 Decoder-only?

- **Encoder-Decoder**:双向注意力,适合理解类任务(NLU),如 BERT。
- **Decoder-only**:因果注意力(只看左侧),天然适配自回归生成,且把所有任务统一为 next-token prediction。统一目标带来统一优化、易扩展、易复用——这是工程上的胜利。

核心模块串联如下:

```text
Token + Position Embedding
   │
   ▼
┌────────────────────────────┐
│ x = x + Attn(LN(x))        │  ← Pre-Norm 残差
│ x = x + FFN(LN(x))         │
└────────────────────────────┘   × L 层
   │
   ▼
LM Head (常与 Embedding 权重共享) → 词表分布
```

几个工程细节值得深究:

- **位置编码**:绝对正弦编码不可外推;旋转位置编码 **RoPE** 把位置信息以旋转矩阵 `R_θ` 乘入 Q、K,使内积 `<q_m, k_n>` 只依赖相对位置 `m-n`,兼具相对位置的表达力与外推性,成为当前主流。
- **LayerNorm**:Pre-Norm(先 LN 再进子层)比 Post-Norm 训练更稳定,梯度流不经过 LN 阻塞,大模型几乎清一色 Pre-Norm。
- **残差连接**:为深层网络提供"高速公路",缓解退化,是堆到百层的前提。
- **FFN**:两层线性 + 激活(ReLU→GELU→SwiGLU)。SwiGLU 引入门控 `FFN(x) = (xW_1 ⊙ σ(xW_gate))W_2`,效果更优但参数翻 2/3,实践中常同步缩小隐藏维。

## 自注意力机制深入:Q/K/V 的物理直觉

注意力本质是"带权检索"。把当前 token 的隐状态投影成三份:

- **Q(Query)**:我想查什么?
- **K(Key)**:我有什么可被匹配的标签?
- **V(Value)**:实际要返回的内容。

相似度用点积衡量,softmax 归一化为权重后对 V 加权求和:

```text
Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V
```

**为什么除以 √d_k?** 当 d_k 较大时,`q·k` 是 d_k 个独立项之和,方差量级为 d_k,点积绝对值变大,softmax 被推到梯度饱和区(几乎 one-hot),训练停滞。除以 √d_k 把方差缩回 1 量级,梯度保持健康——这是数值稳定性的关键。

**多头注意力(MHSA)**:把 d 拆成 h 个头,每头独立做注意力再拼接。不同头可关注不同子空间(语法、共指、长程),且各头计算独立、可并行。

**因果掩码(Causal Mask)**:在 softmax 前把 i < j 的位置置 -∞,使位置 i 看不到未来,实现自回归。掩码一次定义,Prefill 阶段整张注意力图统一应用。

**注意力变体演进**:

| 变体 | Q 头数 | K/V 头数 | 说明 |
|---|---|---|---|
| MHA | h | h | 标准,质量最佳 |
| MQA | h | 1 | K/V 全共享,显存/吞吐最优,质量略降 |
| GQA | h | g(1<g<h) | 折中,分组共享,Llama 2/3 主力 |

MQA/GQA 的价值在推理时尤为突出——它们直接压缩 KV Cache,这是后文推理优化的伏笔。

## 训练三阶段:从"续写"到"对齐"

LLM 的能力是三段式锻造的:

**1. 预训练(Pretraining)**

目标极简:next-token prediction,最小化交叉熵:

```text
L = - Σ_t log P(w_t | w_{<t}; θ)
```

海量文本(万亿级 token)上自回归训练,学到语法、世界知识、常识。数据配比(Web/Common Crawl、代码、论文、多语)决定能力分布——代码数据显著提升推理链能力。Tokenizer(BPE)把词表压缩到 3 万~10 万,平衡序列长度与词表稀疏。

**2. SFT 监督微调**

预训练模型只会"续写",不会"听指令"。SFT 用高质量(指令, 回答)对,以同样的 next-token loss 微调,只在回答部分计算 loss,学会指令跟随、格式遵循。这是从"语言模型"到"助手"的范式转换。

**3. RLHF / RLAIF 对齐**

SFT 模型仍会幻觉、产出有害内容。对齐阶段引入人类偏好:

- 训练**奖励模型 RM**:对同一 prompt 的多个回答打分,拟合 `loss = -log σ(r(x, y_w) - r(x, y_l))`。
- 用 **PPO** 在线采样并用 RM 奖励优化策略,加 KL 惩罚防止偏离 SFT 分布。
- **DPO**(Direct Preference Optimization)更简洁:直接由偏好对推导出最优策略,省去 RM 与在线采样,工程友好,渐成主流。

<Badge text="提示" type="warning" /> 对齐并非"让模型更聪明",而是"让模型行为符合预期",它本质是在能力上限内做约束,过度对齐会损害能力(alignment tax)。

## 推理过程:Prefill、Decode 与 KV Cache

推理分两阶段,理解它们是理解一切推理优化的前提:

- **Prefill**:处理输入 prompt,一次性并行算出所有位置的 K/V 并缓存。计算密集型,产出第一个 token(对应 TTFT 指标)。
- **Decode**:逐 token 自回归,每步用上一步输出作输入,仅算新 token 的 K/V 追加进缓存。显存带宽密集型。

**KV Cache**:把历史 token 的 K/V 缓存下来,避免每步重算。代价是显存:`size ∝ L × seq_len × d × 2 × batch`,随上下文线性增长,长文本下显存压力巨大。

这也解释了为何 MQA/GQA 如此重要:它们把 K/V 头数从 h 压到 1 或 g,直接把 KV Cache 显存降一个量级,从而提升可服务 batch 与吞吐。vLLM 的 PagedAttention 则把 KV Cache 像 OS 分页一样管理,解决碎片化,显存利用率逼近上限。

## 采样与解码策略:多样性的数学

生成时,模型输出的是词表上的概率分布 p。如何采样决定风格:

- **Greedy**:每步取 argmax,确定但易陷入重复循环。
- **Temperature**:`p_i' = softmax(z_i / T)`。T→0 趋近 greedy,T>1 压平分布、增加多样性,本质是调节 logits 的"锐度"。
- **Top-k**:只在概率最高的 k 个 token 中重采样,过滤长尾噪声。
- **Top-p(Nucleus)**:选累积概率 ≥ p 的最小集合,自适应——分布尖锐时集合小,平坦时集合大,比 Top-k 更鲁棒。
- **Repetition Penalty**:对已出现 token 的 logits 除以 >1 的因子,抑制复读。实践中常 Temperature + Top-p + 轻度 repetition penalty 组合。

## 上下文窗口与长文本:外推的根因

上下文窗口受双重制约:

1. **KV Cache 显存**:随序列线性增长,32K~128K 已是硬件极限的硬约束。
2. **位置编码外推**:RoPE 训练时见过的最大位置有限,超出后注意力分布畸变,性能骤降。

长度外推方案围绕 RoPE 展开:

- **位置插值(PI)**:把长序列的位置线性压缩到训练区间,简单但损失分辨率。
- **NTK-aware 插值**:改 RoPE 的 base θ,高频分量少缩放、低频多缩放,保留局部精度,效果优于 PI。
- **YaRN、LongRoPE**(实验性,以官方为准):进一步精细化缩放曲线。

注意力侧则有**稀疏注意力**(只关注局部窗口 + 少量全局 token)、**分块/滑动窗口注意力**(如 Mistral 的 sliding window)等思路,把 O(n²) 降为 O(n·w)。

## 幻觉与局限:为什么需要 RAG 与 Agent

LLM 本质是概率生成器,**没有真值校验机制**:它在分布上"流畅地编",而非"检索事实后陈述"。这导致:

- **幻觉**:看似合理的错误事实,尤其在低频知识上。
- **知识截止**:训练数据有截止日期,无法知晓之后事件。
- **推理薄弱**:长链推理易累积误差,复杂算术/规划不可靠。

正因如此,**RAG**(检索增强生成)用外部知识库提供事实锚点,**Agent** 用工具调用与多步规划补足推理与时效性。这两者是当前把 LLM 落地的工程主干,也是后续专栏文章的主题。

## 前沿概览

<Badge text="实验性" type="info" /> 前沿特性发展迅速,以下以官方论文/发布为准:

- **MoE 混合专家**:每个 token 只激活少数专家(如 8 选 2),用稀疏激活把总参数做大而激活算力不变,DeepSeek/Mixtral 走通此路。代价是显存占用 = 总参数,需更高显存。
- **推理模型(o1/R1 类)**:把 test-time compute 作为新维度——训练模型在推理时产出长 CoT,用强化学习奖励"可验证的正确性"。本质是把"思考"显式化并优化其过程,在数学/代码上显著超越直接采样。
- **多模态**:视觉 token 经投影层进入语言模型的 token 流,统一为序列建模,VLM 成为标配。

## 小结

LLM 的核心可浓缩为:Transformer 架构 + 自回归预训练 + 对齐微调 + KV Cache 推理。深入理解自注意力的 `QKᵀ/√d_k`、因果掩码、RoPE 外推、三阶段训练与 Prefill/Decode 两段式推理,就握住了几乎所有 LLM 工程优化的根——从 MQA/GQA 到 PagedAttention,从 DPO 到 RAG/Agent,都是这些原理的延伸。下一篇将聚焦 RAG 的检索-生成全链路工程实现。
